# homebrew-arclio

Homebrew tap for [Arclio](https://arclio.net) — a free, open-source desktop app that downloads videos, audio, playlists, and subtitles from YouTube and 2000+ other sites.

## Install

```bash
brew install kemzang/arclio/arclio
```

## Update

`Casks/arclio.rb` is rewritten automatically by [Arclio's release pipeline](https://github.com/kemzang/Arclio/blob/main/.github/workflows/release.yml) on every stable release. No manual edits needed.
